GROOVE MOTION Analytics

自分のチャンネルを知り、次のプレイリストへ。

GROOVE MOTION Analyticsは、YouTubeチャンネル「GROOVE MOTION」の所有者本人が、自分の動画の実績を取得し、音楽動画の企画・タイトル・サムネイル・構成の改善に役立てるための個人用分析アプリです。

GROOVE MOTIONのYouTubeチャンネル

アプリの機能

  • YouTube Data APIで、本人の動画一覧・タイトル・公開日時などを取得します。
  • YouTube Analytics APIで、再生回数、総再生時間、平均視聴時間、視聴者維持率、流入元、登録者増減を取得します。
  • YouTube Reporting APIで、インプレッションとクリック率の日次レポートを作成・取得します。

読み取り専用の接続

Googleの認証画面で、YouTubeアカウントの表示とYouTubeアナリティクスレポートの表示を許可して利用します。動画の投稿・編集・削除やチャンネル設定の変更は行いません。日次分析レポートの作成設定のみを行います。

このサイトはアプリの説明ページです。分析結果、認証情報、楽曲、画像、動画を一般公開するものではありません。一般向けのログイン機能は提供していません。

データの取り扱い

認証情報と取得結果は、所有者が利用するPCのローカル環境に保存します。詳しくはプライバシーポリシーと利用案内をご覧ください。

About this app

GROOVE MOTION Analytics is a personal tool for the owner of the GROOVE MOTION YouTube channel. It retrieves channel and video performance using the YouTube Data, Analytics and Reporting APIs. It does not upload, edit or delete videos. This public website contains documentation only; it does not publish channel analytics or credentials.
